# 对话前端审查

范围仅限前端样式和加载图标，保留业务状态、接口、Brain 和用户数据。

先建立卡片正文间距回归检查，再修复诊断列表缺失的 padding，并统一结果卡片、长链接、项目标题和窄屏换行。参照用户 Claude 截图采用低对比侧栏、克制字号、居中阅读列和轻量输入框，保留亮暗主题与现有快捷键。加载图标采用用户提供的双圆 SVG，增加唯一 filter ID 和减少动态效果支持。

验证：前端契约检查、构建、浏览器查看；检查正文到卡片边框的距离、长文本以及窄屏溢出。开源参考 assistant-ui/assistant-ui 与 danny-avila/LibreChat，仅参考结构，不新增依赖。
