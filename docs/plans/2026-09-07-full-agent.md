# 真实求职 Agent 与账户持久化

## 本轮目标与依据

以用户本轮要求及最近的全屏视频提示词为准。恢复 CloudFront 全屏视频、Inria Serif、白色导航、#2B3534 输入区；维持后续确认的单一聊天入口。旧的关键词分流不能作为大模型 Agent 交付。

## 实施决策

- React/Vite + Express 保留，前后端同源。登录页、空会话采用视频首屏，消息态转入专注对话。
- 本机直接可运行的 SQLite 数据库位于 data/resume-protocol.sqlite，支持配置数据目录；账户、哈希会话、用户数据、会话和源文档按用户隔离。旧的远期 PostgreSQL/监控平台设计不是当前聊天版本的实施基线。
- 密码使用随机盐 scrypt，服务端随机令牌会话，浏览器仅保存 HttpOnly cookie。敏感接口必须鉴权，所有写入校验来源。
- MiniMax Anthropic-compatible Messages API 运行有限步工具循环。模型自主选择分析材料、查询岗位、选择目标、生成简历、面试准备工具；工具结果回传模型再生成答复。流式状态来自真实调用。
- 上传材料与模型回复持久化。新资料/新 JD 使旧生成结果失效。历史恢复不能依赖浏览器 localStorage。
- 导出完整岗位版为 Markdown/JSON，并可通过打印导出 PDF。保留源材料用于核对事实。
- 不自动投递或向招聘方发消息。

## 验收

1. 注册、登录、退出、刷新恢复；密码非明文；未登录401；跨用户读取/修改/删除失败。
2. 重开数据库后账户、会话、材料和简历仍存在。
3. 真实 MiniMax 请求成功，工具调用多轮协议测试通过；无密钥或 API 故障明确报错，不伪装成功。
4. 真实对话完成材料分析、目标岗位、定制简历、面试准备；无关键前提时会问用户。
5. 上传、历史切换、新建、删除、导出在界面实际可操作；移动390px与桌面浏览器验证。
6. 全量单元与集成测试、生产构建通过；密钥不进入前端产物和版本控制。

## 本轮分工

- 账户与数据库：独立实施及两用户/重启测试。
- 前端：按上述 API 合同重建、响应式与交互测试。
- 主线程：模型工具循环、API 集成、真实调用、文档和最终验收。
