# Brain 决策边界

dbs 路由至 dbs-deconstruct：将“大脑”还原为可验证的动作选择，而不是另一个模糊提示词。用户已明确授权实现，不需要再次确认设计。

问题：材料预检查先于理解，短材料直接报错；流程将口述视为不合格简历，并可能跨求职者复用旧资料。

实现：每轮通过独立模型调用生成简短结构化决策；中央规则统一注入，代码校验动作集合、事实引用和对象切换依据。对象切换保留旧上下文但隔离模型输入。缺失或无效理解禁止工具写入。模型审校同时覆盖口述，不能升级主观能力评价。

验证：Brain 回归覆盖短材料、越权工具、无依据切换、跨轮对象隔离、对象不明与无效输出；原工具测试隔离 planner 并继续验证执行逻辑；默认模型使用合成对话验证第三方求职场景；完整 npm test 验证其他流程。

边界：Brain 的语义判断不是确定性真理；代码能约束工具和引用，不能证明所有自然语言都正确。当前完整简历生成工具仍有资料与目标条件，未在本次中央规则改动中开放不完整 PDF 草稿。不要宣称这个能力已经完成。每轮新增意图识别模型调用，口述答复也需要事实审校。
