# Resume Protocol Agent Gateway 设计

## 选择

采用“全屏视频 Agent 门厅 + 现有深度工作台”。聊天入口负责理解用户要做的事与检查前置条件，结构化工作台继续承载资料编辑、岗位选择、简历预览与面试计划。

```text
┌──────────────────────── Video / Full viewport ────────────────────────┐
│ Nav                                                                   │
│ 让一次对话，启动整个求职流程                                           │
│                                                                       │
│          ┌──────── Protocol Command Deck ────────┐                    │
│          │ recent user / agent reply             │                    │
│          │ textarea                         send │                    │
│          │ 诊断简历  匹配岗位  定制简历  准备面试 │                    │
│          │ 资料●  JD○  简历○  面试计划○          │                    │
│          └───────────────────────────────────────┘                    │
└───────────────────────────────────────────────────────────────────────┘
┌──────────────────────── Deep green promise ───────────────────────────┐
│ 不是多一个聊天框                  是一个知道下一步的求职 Agent         │
└───────────────────────────────────────────────────────────────────────┘
┌──────────────────────── Existing structured workflow ─────────────────┐
```

## 行为

- “诊断/分析/简历问题”触发资料分析；没有文本时定位到资料输入。
- “找岗位/校招/实习/JD”打开岗位雷达。
- “定制/生成/改写”在资料和岗位齐备时生成岗位版；否则回复缺少哪一步。
- “面试/复习/追问”在已有岗位版时定位到面试作战室；否则引导先生成岗位版。
- 快捷按钮只填写并立即发送明确任务，不制造不可撤销操作。

## 视觉自检

提示词的医疗语言与 Resume Protocol 无关，已全部替换；保留视频、深墨绿输入舱、Inria Serif 与逐词出现。为了避免变成通用 AI landing page，加入真实上下文就绪轨和可路由的工具动作，这是本产品独有的记忆点。
