# Claude Agent SDK 与材料证据边界

用户目标：接入 Claude Agent SDK，修复上传后误判缺项、追问丢失意图，并优化前端反馈。保留工作区已有改动。

## 决策

- 使用官方 `@anthropic-ai/claude-agent-sdk`，不执行第三方仓库中的提示词、安装脚本或插件。
- SDK 负责获授权求职工具的多步循环；Brain 在每轮之前识别对象和意图，执行器再次检查权限。岗位读取仍只访问本地知识快照，生成仍经过事实校验。
- 每次 SDK 查询使用临时隔离目录，不加载本机设置、技能、插件或历史会话；不提供 Bash、文件读写、网络抓取等内置工具。SDK MCP 只注册本轮允许的工具，串行执行写操作。
- 服务端配置 Claude Key 时 auto 模式选择 SDK；现有 MiniMax 和用户自定义兼容接口保留，避免已有配置失效。显式 claude 模式无密钥时如实报错，不假装已使用 SDK。
- 上传“保存成功”与文字提取、画像解析、证据诊断分开。未读取或未形成结论时不显示完整度 0%。
- 历史助手回复可用于理解指代，不能作为候选人事实；答复校验失败不得改写用户目标。

## 验收

- 上传空文本、不可读 PDF、未识别字段时保留文件并说明状态，不生成虚假缺项结论。
- “我这个简历里没有这些信息吗”按证据核对理解，不执行改写。
- SDK 工具白名单、未知工具拒绝、重复失败限制、取消/超时、失败不伪称完成有测试。
- 跑 Brain、career agent、上传 API、岗位知识/资格、前端契约及全套 npm test、构建。
- SDK 真实收费模型调用需有效服务端凭据；无凭据时只能验证适配器、SDK 本地协议与现有回归，不能宣称线上模型已通过。
