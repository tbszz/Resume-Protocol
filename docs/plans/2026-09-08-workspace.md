# 简历工作区改版与验收

用户明确授权实现，按独立工作流并行推进，不要求额外设计审批。

## 用户结果

从首页 Get Started 进入求职工作区：左侧项目/会话，中间自然对话，右侧原简历、证据批注和优化稿；能下载PDF与可编辑DOCX。默认模型不出现在会话中，允许账户级自定义API。岗位先判断招聘资格再排序，建议必须回到真实原文、修改动作和求职用途。

## 设计

- 首页参考附件的白色编辑式结构、新指定视频播放一次，品牌与文案保持简历产品语义。导航右侧登录注册。
- 工作区三栏：240px项目树 / minmax(320px,1fr)聊天 / 约400px预览，窄屏切换预览和抽屉，输入框属于聊天栏布局，不使用覆盖全屏的fixed定位。
- 亮色 #ffffff/#f7f7f8/#18181b/#71717a/#e4e4e7，暗色 #000000/#111111/#fafafa/#a1a1aa/#292929。工作区不用视频和衬线大段回复。
- 首页展示字体用附件衬线方案，工作区正文用Inter/系统中文无衬线，14–15px正文、1.7行距。加载采用四色小点与简短真实进度，尊重减少动画偏好。
- 批注的引用、原因、可执行建议与PDF高亮构成产品主要视觉，不堆装饰卡片。

## 实现边界

保留现有React/Vite技术栈，不因参考提示中的框架清单无故改写为TypeScript/Tailwind。不改品牌为Aethera金融产品。不增加假OAuth按钮；实际账户鉴权保持可用。项目数据增量迁移不删除历史。

## 验证

1. 硬门槛：本科vsPhD、明确资历不足、不明境外工作许可、过期职位、领域错配及正常通过。
2. 账户隔离：项目、模型配置、附件、优化稿下载；密钥加密且不回显；自定义endpoint拒绝私网与重定向。
3. 生成事实：源引用可定位，无凭空指标，PDF中文文本、分页、DOCX可编辑内容与高亮批注。
4. 浏览器：首页进入、登录注册、项目与会话、亮暗切换、上传、真实模型批注、下载、刷新恢复；桌面/窄屏无重叠或横向溢出。
5. 全量测试、生产构建、diff检查、独立评审。
