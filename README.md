# Resume Protocol

Resume Protocol 是一个本地运行、以对话为唯一入口的求职 Agent。界面采用类似 Codex 的会话结构：左侧保存聊天记录，中央只有消息流和输入框；没有额外的结构化工作台或页面下方功能区。

## 对话内置能力

- 简历诊断：直接粘贴简历，或上传 PDF、Word、TXT 文件，返回完整度、优势和待补证据。
- 岗位匹配：根据当前资料与输入方向返回岗位卡，可在消息中选择目标岗位。
- 岗位版简历：使用当前职业画像和目标 JD 生成针对性的技能排序、项目 bullet 与匹配度。
- 面试准备：从岗位版简历生成技术主线、项目深挖问题和七天复习计划。
- 自定义 JD：把完整岗位描述粘贴进对话即可设为当前目标。

所有前置条件都在聊天中补齐。Agent 不会把用户带到另一个表单、雷达或编辑页面。

## 聊天记录

聊天与每个会话的职业上下文保存在浏览器 localStorage 中，键名为 resume-protocol.chat.v1。刷新页面后，消息、职业画像、目标岗位、岗位版简历和面试结果仍会恢复。

当前没有登录或云同步功能；不同浏览器和不同设备之间不会同步聊天。

## 启动

运行 npm install，然后运行 npm run app。

打开 http://127.0.0.1:8787。

开发模式运行 npm run dev。

## 测试

运行 npm test 和 npm run build。

测试覆盖会话创建与删除、自动标题、上下文更新、浏览器存储恢复、诊断结果格式化、Agent 意图与前置条件，以及“旧工作台已从前端移除”的界面契约。

## 本地边界

- 聊天记录只保存在当前浏览器。
- 简历生成基于用户提供的事实，不自动补造职责或指标。
- 岗位库和简历生成继续复用现有 Express API。
- Boss 自动化相关后端代码仍保留，但纯聊天界面不会启动真实投递。
